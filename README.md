# :european_castle: :book: Elena: A Short Visual Novel

## What is Elena?

Elena is a short visual novel being developed for [⛵Shipwrecked](https://shipwrecked.hackclub.com/) that tells the story of the Kindgom of Carisia and their three princesses: Katherine, the oldest daughter, Theodora, the middle daughter, and you, Elena, the youngest daughter. Make choices (that don't *really* matter), read all that juicy text (or don't!), and find out what's truly going on in Carisia...

![A screenshot of Elena. It shows a character named Mother saying something, with two dialouge choices. All of the art is pixel art.](https://github.com/user-attachments/assets/a7cacce0-ed49-4daf-9146-d0d7207173cb)

## How to Install Elena (MacOS)

1. Download the MacOS release version from the releases tab.
2. Unzip the file if it didn't already unzip and attempt to open it.
3. You should see an error saying something to the effect of it "can't be opened because Apple cannot check it for malicious software." Click OK.
4. Go to System Preferences and to Security and Privacy.
5. In the General tab, there should be a notice towards the bottom to the effect of "Elena was blocked from us because it is not from an identifed developer." Click Open Anyway.
6. There should be another window that pops up saying the same error as in Step 3. This time, click Open.

![A screenshot of the MacOS version of Elena.](https://github.com/user-attachments/assets/46c4a209-8435-443c-913f-283413f089ae)

9. Elena should be running now!

## How to Install Elena (Windows)

1. Download the Windows release version from the releases tab.

![Screenshot Elena1](https://github.com/user-attachments/assets/d2e4ff5d-1b9f-4363-8fb9-09cd27029c83)

2. Right click the compressed folder and press Extract All.

![Screenshot Elena2](https://github.com/user-attachments/assets/65fceae5-cd64-4205-b7b6-600163760e07)

3. Press Extract.

![Screenshot Elena3](https://github.com/user-attachments/assets/149eb92c-3391-4c5a-b85d-936ca020e722)

4. Go into the new File Folder (instead of the Compressed (zipped) folder).

![Screenshot Elena4](https://github.com/user-attachments/assets/bece3966-0b37-4055-96fa-77aa7c7098f1)

5. Go into the folder labeled Elena [version number]

![Screenshot Elena5](https://github.com/user-attachments/assets/87be39ba-7526-4c02-95df-9419dfc913e5)

6. Right click on Elena and select Open.
7. A notice might appear saying "Windows protected your PC". Click the More Info button under the smaller text.
8. A new button will appear labeled Run anyway. Click it.

![Screenshot Elena6](https://github.com/user-attachments/assets/58baf440-2540-40da-87f6-2fcac69ed5ef)

9. Elena should be running now!
